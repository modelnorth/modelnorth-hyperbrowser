# 🏛️ ARCHITECTURE.md — ModelNorth HyperBrowser Engine

Technical Specification and System Design for **ModelNorth HyperBrowser**, a high-performance, local-first web automation agent.

---

## 1. System Overview & Design Rationale

Traditional browser agents suffer from two compounding failure modes:
1. **The Multimodal Latency Tax**: Transmitting full-page screenshots to cloud vision models on every micro-decision adds 5–15 seconds and \$0.05–\$0.30 per step.
2. **The DOM Blindspot**: Purely textual/DOM-based agents fail abruptly when encountering `<canvas>`, interactive WebGL maps, complex dynamic SVGs, or visual CAPTCHAs.

**ModelNorth HyperBrowser** resolves this trade-off using a **Tri-Tier Hybrid Engine**:

```
                       NATURAL LANGUAGE GOAL
                                 │
                                 ▼
         ┌───────────────────────────────────────────────┐
         │         Browser Session Harness (CDP)         │
         └───────────────────────┬───────────────────────┘
                                 │ Page Snapshot
                                 ▼
 ┌───────────────────────────────────────────────────────────────┐
 │ TIER 0: In-Browser Heuristic Compiler (V8 Runtime)            │
 │ • Latency: < 1 ms  |  Cost: $0.00                             │
 │ • Solves 70% of deterministic buttons, forms, and navigation  │
 └───────────────────────────────┬───────────────────────────────┘
                                 │ Ambiguous / Complex
                                 ▼
 ┌───────────────────────────────────────────────────────────────┐
```

## 2. The Tri-Tier Execution Pipeline

### Tier 0: In-Browser Fast-Path Compiler (`fastpath.js`)
- Executed directly within Chrome's V8 context using `Runtime.evaluate`.
- Matches explicit intent patterns (e.g., `click "Submit"`, `type "Zurich" into "Where from?"`) against visible, accessible DOM nodes.
- **Latency**: `< 1 ms`. Zero inter-process serialization.

### Tier 1: Local System 1 Decision Model (`decision_local.py`)
- Reads the atomic element table generated by `snapshot.js`:
  ```text
  [1] button    Search Flights
  [2] combobox  Origin airport · San Francisco
  [3] combobox  Destination    · empty
  [4] textbox   Departure date · empty
  ```
- Evaluates the state using **HyperLocal ONNX** (INT8 quantized) in a single forward pass.
- Returns the winning operation (`CLICK`, `TYPE_TEXT`, `SELECT`, `SCROLL`, `DONE`) and target index speculatively.
- If the operation is `TYPE_TEXT`, queries a local text helper (e.g. `Qwen2.5-Coder-1.5B` via Ollama/llama.cpp) in ~40ms.
- **Latency**: `7–15 ms`.

### Tier 2: Multimodal Vision Sentry (`vision_sentry.py`)
- **Activation Triggers**:
  - `document.querySelectorAll('canvas, iframe[src*="captcha"], iframe[src*="turnstile"]') > 0`
  - Tier 1 decision confidence $< 0.65$ or consecutive loop failure $> 2$.
- Takes a high-resolution viewport capture via `Page.captureScreenshot`.
- Sends the image to **Gemini 2.5 Flash** with a structured coordinate prompt.
- Receives exact normalized point `[y, x]` coordinates (0–1000 scale) and executes native CDP mouse clicks (`Input.dispatchMouseEvent`).
- **Latency**: `250–450 ms`.

## 3. DOM Extraction & Action Space Geometry (`snapshot.js`)

To guarantee zero coordinate drift and prevent stale element references:
1. **Atomic Evaluation**: All interactive candidates (`button`, `input`, `select`, `a`, `[role]`, `[tabindex]`) are indexed in a single JavaScript pass.
2. **Occlusion & Viewport Filtering**: Elements hidden by overlays, `display: none`, or outside the current scroll viewport are filtered out prior to serialization.
3. **Persistent Node Reference**: Each indexed candidate stores its direct DOM node identifier for instant execution.

## 4. Latency & Resource Budget

| Operation Stage | Legacy Cloud Agent | ModelNorth HyperBrowser (Hybrid) | Speedup Factor |
| :--- | :--- | :--- | :--- |
| **DOM Snapshot Extraction** | 30–50 ms | 15–25 ms | ~2x |
| **Standard Decision Cycle** | 200–500 ms (API roundtrip) | **1–15 ms (Local)** | **15x – 30x** |
| **Text Generation** | 200–400 ms (OpenRouter) | 30–60 ms (Local Ollama) | ~5x |
| **Canvas / CAPTCHA Fallback** | ❌ Unsupported (Fails) | **~350 ms (Gemini Flash)** | $\infty$ |

## 5. Security, Privacy & Sovereignty

- **Data Privacy**: No DOM structures, form values, customer credentials, or session cookies leave the local machine during Tier 0 and Tier 1 operations.
- **Strict Coordinate Safety**: Pixel clicks dispatched in Tier 2 are bounded strictly to the active target bounding box.
